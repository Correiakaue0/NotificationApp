# Projeto MVC com .NET 8, SignalR, Chat e Notificações

Este projeto é uma aplicação web desenvolvida utilizando o padrão **MVC** com **.NET 8**, integrando **SignalR** para funcionalidades de **chat em tempo real** e **notificações**.

## 📋 Descrição

A aplicação permite que usuários se comuniquem por meio de uma interface de chat interativo. Além disso, o sistema inclui um mecanismo de notificações em tempo real, proporcionando uma experiência mais dinâmica e conectada.

## ⚙️ Tecnologias Utilizadas

- .NET 8
- ASP.NET MVC
- SignalR
- C#
- HTML/CSS
- JavaScript

## 💡 Funcionalidades

- ✅ Interface de chat em tempo real
- ✅ Sistema de notificações ao vivo
- ✅ Comunicação instantânea entre usuários
- ✅ Estrutura MVC organizada e escalável
